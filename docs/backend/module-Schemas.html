Module: Schemas

Define los esquemas de validación de datos para la entidad 'Equipo' utilizando Zod. Estos esquemas se utilizan en los controladores para validar los datos de las peticiones HTTP antes de que lleguen a la capa de servicio, asegurando la integridad de los datos.

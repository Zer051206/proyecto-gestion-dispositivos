Module: Config

Archivo de configuración centralizado para la conexión de Sequelize a la base de datos MariaDB. Lee las credenciales y parámetros de conexión desde las variables de entorno, permitiendo configuraciones distintas para diferentes entornos como desarrollo y producción.

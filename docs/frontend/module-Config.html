Module: Config

Configuración centralizada de la instancia de Axios para la aplicación. Este módulo crea una instancia de Axios con interceptores preconfigurados para manejar automáticamente la autenticación (añadiendo el token JWT a las cabeceras) y la renovación de tokens de acceso expirados sin interrumpir la experiencia del usuario.

Una cola para almacenar temporalmente las peticiones que fallaron con un error 401 mientras se está intentando renovar el accessToken. Cada elemento en la cola es una Promesa con sus funciones resolve y reject.

(inner) isRefreshing :boolean

Una bandera para prevenir múltiples llamadas simultáneas al endpoint de refresh. Si ya se está refrescando el token, las nuevas peticiones fallidas se encolan en lugar de iniciar un nuevo proceso de refresh.

Methods

(inner) processQueue(error, token)

Procesa todas las peticiones encoladas. Si la renovación del token fue exitosa, reintenta cada petición con el nuevo token. Si falló, rechaza todas las peticiones encoladas.

Parameters:
Name Type Description
error Error | null

El error ocurrido durante la renovación del token, o null si fue exitosa.
token string | null

El nuevo accessToken, o null si la renovación falló.

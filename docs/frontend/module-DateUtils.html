(inner, constant) dateTimeOptions :Intl.DateTimeFormatOptions

Opciones de configuración para el formato de fecha y hora usando toLocaleString. Especifica el formato numérico para año, mes y día, y el formato de 2 dígitos (24 horas) para la hora, los minutos y segundos.

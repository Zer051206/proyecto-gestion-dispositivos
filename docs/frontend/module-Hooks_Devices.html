Module: Hooks/Devices

Hook personalizado para gestionar la lógica del formulario dinámico de creación de equipos. Este hook encapsula la validación con Yup (incluyendo reglas condicionales basadas en el rol del usuario), el estado del formulario con Formik y la lógica de envío de datos a la API.

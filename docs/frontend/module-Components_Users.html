Module: Components/Users

Componente de React que renderiza un formulario modal para la creación de uno o más usuarios. Utiliza un patrón de formulario dinámico con Formik y FieldArray, permitiendo al administrador añadir o quitar formularios para usuarios individuales dentro de una misma transacción. Este componente es responsable de obtener los datos de catálogo necesarios (tipos de identificación, centros de operación) para sus campos.

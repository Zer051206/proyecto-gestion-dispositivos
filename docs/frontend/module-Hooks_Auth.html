Module: Hooks/Auth

Hook personalizado que encapsula toda la lógica y el estado para el formulario de inicio de sesión. Utiliza Formik para la gestión del formulario, Yup para la validación de datos del lado del cliente, y se integra con el store de autenticación global (Zustand) para manejar la sesión del usuario.

(async, inner) onSubmit(values, formikHelpers)

Función que se ejecuta al enviar el formulario, solo si la validación es exitosa. Realiza la llamada a la API de login, maneja la respuesta de éxito o error, actualiza el estado global y redirige al usuario.

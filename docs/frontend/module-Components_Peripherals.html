Module: Components/Peripherals

Componente de React que renderiza un formulario modal para la creación de uno o más periféricos. Utiliza un patrón de formulario dinámico con Formik y FieldArray, permitiendo al usuario añadir o quitar formularios para periféricos individuales dentro de una misma transacción. Este componente es responsable de obtener los datos de catálogo necesarios (tipos de periféricos, centros de operación) para sus campos.

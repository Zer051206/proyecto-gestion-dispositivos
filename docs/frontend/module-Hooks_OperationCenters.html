Module: Hooks/OperationCenters

Hook de React para gestionar la lógica del formulario de creación de Centros de Operación. encapsula la validación con Yup, el manejo de estado con Formik para formularios dinámicos (FieldArray), y la comunicación con la API para enviar los datos.

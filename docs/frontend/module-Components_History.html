Module: Components/History

Página principal para la visualización del historial y la auditoría. Permite a los usuarios (principalmente Admins) ver un registro de todas las acciones (logs) y de todos los activos dados de baja. Incluye una interfaz con pestañas para navegar entre las dos vistas, así como filtros de búsqueda y ordenación.

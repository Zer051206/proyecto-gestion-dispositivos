Module: Hooks/Catalogue

Hook personalizado para obtener y gestionar los datos de los catálogos de la aplicación. Este hook centraliza la lógica de fetch para múltiples catálogos (ej. tipos de identificación, centros de operación), que son necesarios para poblar los menús <select> en varios formularios.

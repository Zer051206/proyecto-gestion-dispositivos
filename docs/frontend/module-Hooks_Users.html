Module: Hooks/Users

Hook de React para gestionar la lógica del formulario dinámico de creación de usuarios. Se encarga de la validación de datos con Yup, el manejo del estado del formulario con Formik, y el envío de los datos a la API para la creación de múltiples usuarios a la vez.

Module: Utils

Módulo de utilidad para exportar datos a un archivo de Excel. Utiliza las librerías exceljs para construir el archivo y file-saver para descargarlo.

Methods

(async, inner) exportToExcel(assets, fileName) → {Promise.<void>}

Exporta un array de datos de activos (equipos y periféricos) a un archivo .xlsx. Crea hojas de cálculo separadas para cada tipo de activo, aplica estilos a las cabeceras y habilita la funcionalidad de AutoFiltro de Excel.

Parameters:
Name Type Description
assets Array.<object>

El array completo de activos a exportar.
fileName string

El nombre deseado para el archivo (sin la extensión).

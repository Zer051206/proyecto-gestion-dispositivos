Module: Stores/Auth

Contiene el store global de Zustand para la gestión del estado de autenticación en toda la aplicación. Implementa un patrón de sesión persistente con localStorage para una carga rápida y revalidación en segundo plano.

Methods

(inner) checkAuthStatus() → {void}

Revalida la sesión actual en segundo plano llamando al endpoint /auth/me. Se utiliza al cargar la aplicación para sincronizar el estado del frontend con el del backend. Si la revalidación falla, se encarga de limpiar la sesión local.
